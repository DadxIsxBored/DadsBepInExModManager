# Changelog

## 1.1.0 - 2026-09-15

- Added a dedicated DadsEPI custom-slot editor with an active-slot list, one slot-name field, one prefab-list field, and an Add Slot button.
- Hid DadsEPI's individual custom-slot backing fields from the manager while retaining their existing configuration data.

## 1.0.0 - 2026-09-14

- Added an F1 configuration-manager overlay for loaded BepInEx plugins.
- Added mod and setting search, scrollable sections, per-setting reset, reload, save, and cancel controls.
- Added automatic game pausing with restoration of the prior pause, time-scale, cursor, and UI-selection state.
- Added a top-order full-screen raycast blocker plus player, inventory, and pause-menu input guards.
- Revised the package icon with a forged-fantasy adaptation of the supplied BepInEx symbol reference.
